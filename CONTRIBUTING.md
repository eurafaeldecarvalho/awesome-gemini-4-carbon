# Contributing

Add a creation only when you can point at all of the following on a public page.

## Inclusion

- The post or repository is public.
- The author published the prompt. Quote it as they wrote it. If the post only describes the result ("I asked it to build a castle"), it does not qualify. Do not reconstruct, translate, or complete a prompt.
- The result is visible without logging in. A video or page that only appears after login does not qualify. X posts are accepted when a public post API returns the status and the media URL answers without an account. That exception is listed in [`lychee.toml`](lychee.toml) because x.com blocks anonymous link checkers.
- The author is named and linked, with the date of the post (`YYYY-MM-DD`, UTC).
- One entry per creation. A comparison of that same creation is a field on the entry, not a second row.
- An Opus 5.5 comparison is included only when someone published both outputs from the same prompt. Link that post. Do not run a private comparison and paste it here unless you are the repo owner, you say you ran both, and you include the date.
- No NSFW, no harassment, and no fabricated model claims. If the author says Arena showed a different name, keep that sentence.
- Do not upload someone else's video, image, or code. Link the original. Media in this repo is limited to the original social card generated by `scripts/build_readme.py`.

Submissions in Portuguese are welcome. The list itself is in English.

## Entry format

Edit [`data/entries.yml`](data/entries.yml) only, then regenerate the README:

```bash
python3 -m pip install -r requirements.txt
python3 scripts/build_readme.py
python3 scripts/check_x_posts.py
```

```yaml
- id: short-unique-id
  title: Short title
  category: 3d-threejs   # or games, simulations, ui-svg, agents, failures
  featured: 0            # 0, or 1-5 to place it in the top grid
  author:
    name: Display name
    handle: handle
    url: https://x.com/handle
  post: https://x.com/handle/status/123
  date: 2026-10-29
  prompt: "The prompt exactly as published."
  note: "Where on the post the prompt appears."
  verified_on: 2026-10-29
```

Optional fields: `arena_label`, `comparison` (`url`, `handle`) for an Opus 5.5 post that contains the same prompt, `credits` (people the poster names), `related` (`url`, `handle`, `label`).

`scripts/validate_entries.py` checks the shape, ISO dates, and unique post URLs. `scripts/check_x_posts.py` checks the live post.

## Pull requests

Use the pull request template. One creation per pull request is easier to review. Say what you opened and what you did not invent.

## Removals and corrections

If you are the author and want an entry changed or removed, open an issue with the post URL. Credit mistakes are fixed the same way.
